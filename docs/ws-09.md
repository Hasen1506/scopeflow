## Part A (this PR so far)

### L8: workspace split (no behaviour change)

`app/workspace.tsx` (85 KB, one component) is now `app/workspace/**`:

| File | What moved there |
|---|---|
| `shell.tsx` | `Workspace` (default export): header, landing, tabs, project head, preview column, dialogs |
| `state.tsx` | `useWorkspace()`: every piece of state, effect and action of the old component, verbatim, plus shared types/constants (`OvProject`, `Overview`, `moneyMap`, `EMAIL`, `STALE_DAYS`, `Tpl`) |
| `project-list.tsx` | Projects home tab (`projectList`) and `UnsavedCard` |
| `editor.tsx` | Editor fields and step 1 "Scope" (`editorFields`, `scopeStep`) |
| `approval.tsx` | Step 2 "Approval" (`approvalStep`) |
| `changes.tsx` | Step 3 "Changes" (`changesStep`) |
| `money.tsx` | Step 4 "Payment & receipts" (`paymentStep`) with `PaymentPanel`, `PaymentForm`, `RefundForm`, `ReceiptList` |
| `settings.tsx` | Project settings (`settingsStep`) |

How it stays identical: the code was moved by line range with a script; the only generated text is the
hook wrapper/return, the `const {...}=w` destructuring and imports. The section modules are plain render
functions called inline (`{approvalStep(w)}`), not new components, so the React tree, hook order and
DOM are exactly as before; `tests/e2e/golden-flow.spec.ts` and its `__golden__` set are unchanged.
`app/page.tsx` imports `./workspace/shell`.

Test: `tests/ws-09-bundle.test.mjs` (`@covers L8`, run by `test:local` after the build): each workspace
module < 48 KB; the JS the workspace route loads stays under `WS09_ROUTE_JS_BUDGET` (default 2,500,000 raw bytes;
the measured size is printed in CI).
